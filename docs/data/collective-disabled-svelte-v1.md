# Collective recommendation gate

```text
BUS_LINE_RECOMMENDATION=DISABLED
```

The repository contains historical bus-stop references, but it does not contain a current, versioned and fully sourced dataset that proves line, route, direction, stop relationships, service frequency and transfers. The Svelte runtime therefore exposes no bus-line recommendation, route, wait time or stop claim.

Re-enablement requires a dated schema, provenance, territorial coverage declaration, geometric validation and deterministic tests. SUBE remains the current payment reference; it is not evidence for a route recommendation.
