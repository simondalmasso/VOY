## Why is this repository eligible? (<=500 chars)

VOY is an actively maintained open-source mobility project for Argentina focused on source-backed routing and temporal truth. It uses reproducible unit, browser and release gates, provenance checks and fail-closed data handling to avoid fake realtime. The project has a public deployment and ongoing maintainer work across source validation, regression testing, release verification and documentation.

## How will API credits be used? (<=500 chars)

Use credits for core OSS maintenance: regression and PR review, issue triage, source-change investigation, adapter test generation, provenance/documentation upkeep, release verification and bounded maintainer automation. Codex would not become the source of mobility truth; canonical routing/data decisions remain deterministic and source-backed.

## Additional note (<=500 chars)

VOY prioritizes honest degradation: realtime, predicted, scheduled and unknown remain distinct, and missing evidence is never presented as service absence. The project intentionally avoids private transit APIs, fabricated ETAs and heavyweight GIS/3D rewrites when a smaller deterministic approach is sufficient.
